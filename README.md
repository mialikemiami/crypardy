## Troubleshooting

| Problem | Fix |
|-------|-------|
| "Sign-in service not found" | The site didn't deployed right. Lawd!!! Gotta check the functions deployed on Netlify. |
| "No game is running with that password" | Host ain't signed in yet or the password don't match. |
| "Too many wrong passwords" | Wait 10 minutes. |
| No sound on stream | Click anywhere on the stream view once and share the window with sound. |
| Streamer can't share screen | You gotta invite em to speak first. |
| Emote shows up as text | Emote name changed in the server. I gotta fix it in `EMOTES`. |
| Player switched devices | Move they seat in the host view's Scores panel. |
| Changes ain't showing | Redeploy then hard refresh. |
